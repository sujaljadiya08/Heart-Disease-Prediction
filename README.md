# 🫀 Heart Disease Prediction — Machine Learning Web App

An end-to-end machine learning application for predicting the likelihood of heart disease from patient health-related attributes, with an interactive Streamlit interface.

## 📌 Overview

This project demonstrates a complete machine learning workflow — from data preprocessing and model training to model serialization and deployment through a Streamlit web application.

## 🎯 Problem Statement

The objective of this project is to build a binary classification system that uses relevant patient-related attributes to generate a machine learning prediction.

The target classes represent the two classes present in the dataset.

> ⚠️ This project is for educational and machine-learning demonstration purposes only. It is not a medical diagnostic tool and should not be used for medical decisions.

## 🧠 Machine Learning Workflow

### 1. Data Preprocessing

The dataset is prepared for machine learning by performing the required preprocessing and converting the input data into a suitable format for model training.

### 2. Feature Preparation

Relevant patient-related attributes are prepared as model features. Numerical and categorical variables are handled according to the preprocessing pipeline.

### 3. Feature Scaling

Feature scaling is applied where required by the machine learning algorithm. The fitted scaler is saved as:

`scaler.pkl`

### 4. Model Training

Classification models are trained using the prepared dataset.

One of the implemented models is:

`K-Nearest Neighbors (KNN)`

The trained model is serialized so the Streamlit application can load it without retraining every time.

### 5. Prediction

The application follows this inference flow:

User Input
↓
Preprocessing
↓
Scaling
↓
Trained Model
↓
Prediction

## 🎈 Streamlit Application

The Streamlit application provides an interactive interface where users can enter the required patient attributes.

The application processes the inputs using the saved preprocessing components and generates a prediction using the trained machine learning model.

### Run the Application

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
